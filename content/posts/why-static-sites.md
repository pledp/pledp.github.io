title: Why I keep this site fully static
date: 2026-04-20
excerpt: GitHub Pages, no server, no database — a short case for keeping a personal site boring and static.
tags: [meta, web]
---

This site is built with Next.js but exported entirely to static HTML and deployed to GitHub Pages. No server, no database, nothing to keep running.

For a personal portfolio, that tradeoff is an easy call: it's free to host, has effectively zero maintenance burden, and is fast everywhere. The cost is that a post like this one only appears after a rebuild — which, for a blog that gets updated a few times a month, is not a real cost at all.
